7 files: 3 hand-edited `.arb` files plus the 4 Dart files `flutter gen-l10n` rewrites from them.
The 4 generated files are committed in this repository, so they must land in the same commit.

### Goal
`AppLocalizations` exposes 11 new getters plus `categoryDeleteInUse(int count)`, in Portuguese,
English and Spanish.

### Context to read first
1. `lib/l10n/app_pt.arb` — the whole file (58 lines); the template file named by `l10n.yaml`. Keys are flat, in feature order, with no `@` metadata anywhere yet.
2. `lib/l10n/app_en.arb` and `lib/l10n/app_es.arb` — the whole files; they carry exactly the same key set as the template, in the same order.
3. `l10n.yaml` — the whole file (3 lines); `arb-dir: lib/l10n`, `template-arb-file: app_pt.arb`, `output-localization-file: app_localizations.dart`. There is no `output-dir`, so the generator writes next to the `.arb` files, which is why the 4 Dart files are versioned.

Read exactly these. Do not open other files unless a step below names one.

- Do not reorder, rename, or reword an existing key in any of the three `.arb` files.
- Do not edit `lib/l10n/app_localizations*.dart` by hand. They are outputs of step 4.
